# DEAD SIGNAL

A 3D zombie-apocalypse survival horror game built with Godot 4.

## Platforms
- Android (APK)
- Windows (EXE)

## Current prototype
- Fully 3D first-person scene with procedural ruined city blocks
- First-person mouse-look and WASD movement
- Sprint, jump, firearm hitscan, ammo and medkits
- Zombie enemies that chase and attack the player
- Collectible medical kits, ammunition and supplies
- Health, hunger and thirst survival meters
- Foggy post-apocalyptic lighting and HUD

## Controls
- WASD: move
- Mouse: look
- Shift: sprint
- Space: jump
- F / left mouse: fire
- H: use medkit
- E: collect supplies
- Esc: release mouse

## Build
Open this project in Godot 4.x. For Android, install Android build templates and configure the Android SDK/JDK in Editor Settings, then export an APK. For Windows, install export templates and export a Windows Desktop build.

This repository contains the Godot project source. Exported APK/EXE binaries are not included yet.
