# DEAD SIGNAL

**DEAD SIGNAL** is a first-person survival-horror project targeting Android APK and Windows desktop, built with Godot 4.

## Current playable foundation
- Procedural 3D ruined-city blockout with buildings, debris and wrecked vehicles
- First-person mouse-look, walking, sprinting, crouching and jumping
- Camera movement bob and crouch camera-height transition
- Pistol-style hitscan weapon, magazine, reserve ammunition and timed reload
- Four infected archetypes: shambler, runner, brute and night stalker
- Basic infected perception with line-of-sight checks, sound investigation and melee attacks
- Survival meters: health, hunger, thirst and stamina
- Bleeding, medkits, food and water consumables
- Collectible supplies and an in-game status HUD
- Dynamic day/night lighting and fog density
- DEAD SIGNAL icon configured in the Godot project

## Controls
- WASD / arrows: move
- Mouse: look
- Left mouse or F: fire
- Shift: sprint
- C: crouch
- Space: jump
- R: reload
- E: collect supplies
- H: use medkit
- 1: eat
- 2: drink
- Esc: release mouse

## Build
Open project.godot with Godot 4.x. Install matching export templates. Configure Android SDK/JDK for Android export and the Windows Desktop export preset for Windows.

## Honest project status
This is an early gameplay prototype and a foundation for the larger game described in the design brief. It is **not yet** a finished AAA open-world game. Detailed character/weapon animations, authored interiors and landmarks, proper weapon models and audio, advanced weather (rain/lightning), crafting, a full inventory UI, minimap, save system, mobile touch controls, story missions, and performance testing still need to be implemented. APK and EXE binaries have not yet been exported.
